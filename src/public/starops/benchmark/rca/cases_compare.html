RCA Benchmark · 诊断对照

评测对象 3 套:ReAct × PaaS、OpenClaw × PaaS、STAROps RCA。在同一组 40 个注入故障案例上独立做根因排查,评分由 brise 给出(RCA-Bench 自带的评分系统,完整口径见评测基准 §5.2 评估维度分解)。

评分维度与术语
  • O:综合分,取值 0 至 100,O = 0.40·E + 0.30·F + 0.30·P
  • E(定界):根因实体匹配
  • F(定因):故障类型匹配
  • P(过程):推理过程评估

react × paas 与 openclaw × paas 为开源 RCA 框架,接入 UModel observability MCP tools。STAROps RCA 为 STAROps 产品的根因分析模块。三者使用相同的数据集,推理策略不同。
